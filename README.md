## Project Overview

NeuroNote is a **multimodal educational AI system** designed to help students understand biology concepts through both **textual and visual intelligence**.

The project is implemented in **two major phases**:

1. **Text-to-Image Retrieval** – retrieves the most relevant biological diagrams based on a textual response.
2. **Image-to-Text Explanation** – generates accurate biological explanations from a user-uploaded image using Retrieval-Augmented Generation (RAG).

Together, these phases enable **bidirectional understanding between text and images**, making learning more interactive and concept-driven.

---

## Phase 1: Text-to-Image Retrieval

### Objective

Given a **textual response** (generated by the LLM), retrieve the **most relevant biological images** from a dataset using semantic similarity.

---

### Dataset

* Biology images (NCERT Class 11–12)
* Each image is paired with a **descriptive caption**
* Stored in CSV format

---

### Methodology

#### 1. Caption Embedding

* Image captions are embedded using
  `sentence-transformers/all-MiniLM-L6-v2`
* Each caption is converted into a dense semantic vector
* All caption embeddings are stored for reuse

---

#### 2. Response Embedding

* When a user asks a question:

  * The system generates a **textual response** via RAG
  * This response is embedded using the **same embedding model**

---

#### 3. Similarity Matching

* Cosine similarity is computed between:

  * Response embedding
  * Stored caption embeddings
* The **Top-K most similar captions** are selected

---

#### 4. Image Retrieval

* Images corresponding to top-matching captions are retrieved
* These images are displayed alongside the generated answer

---

### Key Outcome

This phase ensures that:

* Images shown are **semantically aligned** with the generated explanation
* Learning is reinforced visually
* The system remains fast and lightweight

---

## Phase 2: Image-to-Text Explanation (RAG-based)

### Objective

Given a **user-uploaded biology image**, generate a **factually grounded textual explanation** using both visual understanding and retrieved textbook knowledge.

---

### System Architecture

This phase integrates:

* **CLIP** for image embeddings
* **FAISS** for image similarity search
* **Vision LLM** for image captioning
* **Text LLM** for explanation generation
* **Retrieval-Augmented Generation (RAG)**

---

### Methodology

#### 1. Image Embedding (CLIP)

* The uploaded image is encoded using CLIP (`ViT-B/32`)
* Produces a **512-dimensional embedding**
* Same embedding space is used for dataset images

---

#### 2. Image Retrieval (FAISS)

* FAISS retrieves **Top-K visually similar images**
* Corresponding captions are extracted as **trusted knowledge**

---

#### 3. Vision-Based Captioning

* A vision-capable LLM generates a **biology-focused caption**
* Captures visual features directly from the image

---

#### 4. Retrieval-Augmented Prompt Construction

The final prompt contains:

* Vision model caption
* Retrieved captions from similar images

Strict instructions are provided to:

* Avoid hallucination
* Use only retrieved and visual context

---

#### 5. Text Explanation Generation

* A lightweight LLaMA model generates:

  * Accurate
  * Student-friendly
  * Biology-specific explanation

---

### Output

The system produces:

* Vision-based image caption
* Retrieved textbook captions
* Final grounded explanation
