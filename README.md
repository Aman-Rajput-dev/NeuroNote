## 📌 Project Overview

**NeuroNote** is a multimodal educational AI system designed to help students understand biology concepts through both textual and visual intelligence.

The system is implemented in **two major phases**:

| Phase | Description |
|---|---|
| 📷 **Phase 1** — Text-to-Image Retrieval | Given a textual response, retrieves the most relevant biological diagrams using semantic similarity |
| 📝 **Phase 2** — Image-to-Text Explanation | Given a user-uploaded biology image, generates a factually grounded explanation using RAG |

Together, these phases enable **bidirectional understanding** between text and images, making learning more interactive and concept-driven.

---

## 🔍 Phase 1: Text-to-Image Retrieval

### Objective

Given a textual response (generated by the LLM), retrieve the most relevant biological images from a dataset using semantic similarity.

### Dataset

- Biology images sourced from NCERT Class 11–12 textbooks
- Each image is paired with a descriptive caption
- Stored in CSV format

### Pipeline

```
User Question
     │
     ▼
RAG Text Response
     │
     ▼
Sentence Embedding (all-MiniLM-L6-v2)
     │
     ▼
Cosine Similarity vs. Caption Embeddings
     │
     ▼
Top-K Matched Images Displayed
```

### Steps

1. **Caption Embedding** — Image captions are embedded using `sentence-transformers/all-MiniLM-L6-v2` and stored for reuse.
2. **Response Embedding** — The LLM-generated text response is embedded with the same model.
3. **Similarity Matching** — Cosine similarity is computed between the response embedding and all caption embeddings.
4. **Image Retrieval** — The Top-K best-matching images are retrieved and displayed alongside the answer.

---

## 🖼️ Phase 2: Image-to-Text Explanation (RAG-based)

### Objective

Given a user-uploaded biology image, generate a factually grounded textual explanation using both visual understanding and retrieved textbook knowledge.

### Architecture

```
Uploaded Image
      │
      ├──► CLIP Embedding ──► FAISS Search ──► Retrieved Captions
      │
      └──► Vision LLM ──────────────────────► Vision Caption
                                                      │
                                                      ▼
                                          RAG Prompt Construction
                                                      │
                                                      ▼
                                          LLaMA Text Explanation
```

### Steps

1. **Image Embedding (CLIP)** — The uploaded image is encoded using CLIP (`ViT-B/32`) to a 512-dimensional vector.
2. **Image Retrieval (FAISS)** — FAISS retrieves Top-K visually similar images; their captions are used as trusted context.
3. **Vision-Based Captioning** — A vision-capable LLM generates a biology-focused caption for the uploaded image.
4. **RAG Prompt Construction** — A grounded prompt is built from the vision caption + retrieved captions, with strict anti-hallucination instructions.
5. **Explanation Generation** — A lightweight LLaMA model produces an accurate, student-friendly biological explanation.

## 🏁 Conclusion

NeuroNote demonstrates a complete multimodal AI pipeline where:

- **Text retrieves images** — semantic search surfaces the right diagram
- **Images generate text** — visual understanding drives accurate explanations
- **Both are grounded via RAG** — reducing hallucination with retrieved context

This two-phase architecture significantly improves learning accuracy, interpretability, and engagement — making it well-suited for real-world educational applications.
